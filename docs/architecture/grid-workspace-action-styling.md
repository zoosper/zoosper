# Grid workspace action styling

The Store Orders workspace exposed persistence forms as a tall sequence of default-styled buttons and full-width name inputs. This phase adds a package-owned action stylesheet that keeps the save/reset controls together, presents named-view forms in compact responsive rows, and applies consistent primary, secondary, danger, hover and keyboard-focus states.

The change is CSS-only. It does not alter mutation actions, CSRF fields, persisted values, permissions or API Grid behaviour.
