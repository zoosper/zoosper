# Grid command bar

Phase 7F removes Grid settings from normal document flow. Saved-view management is opened from a compact, labelled toolbar control and displayed as an anchored panel. Filters, Columns and view management are mutually exclusive. Escape closes the active panel; narrow screens use a bottom drawer.

`Save columns` remains temporarily available inside the hidden management panel for backwards compatibility. It stores the administrator's general visible-column preference independently of named views. `Reset columns` clears that preference. Their removal is deferred to the Grid preference simplification phase so behaviour is not silently deleted during a layout-only build.
