# Zoosper CMS v0.3.0-alpha.2

## Release theme

API, security, modular ownership, and operational recovery.

## Highlights

- Expanded feature-owned PAT-scoped APIs for Page, Menu, Media, Site, Theme, and URL Rewrite capabilities.
- Completed Page lifecycle and revision API foundations, including publication-state orchestration.
- Strengthened stateless HTTP behaviour, exact-origin CORS, authentication controls, media lifecycle safety, and production exception handling.
- Extracted focused Composer packages for logging, cache, shared Marko configuration compatibility, and persisted scoped configuration.
- Preserved database-lazy console recovery, fresh installation, frontend boot, and declarative schema ownership.
- Retired the unused Zoosper-native general method-plugin subsystem rather than maintaining a second interception runtime without production consumers.

## Package architecture completed in this line

- `zoosper/logger`
- `zoosper/cache`
- `zoosper/config`
- `zoosper/scoped-config`

## Upgrade and operational notes

- Run Composer through PHP 8.5.
- Run database migration and module-manifest compilation after deployment.
- Keep runtime cache, logs, sessions, and uploaded media outside source control.
- The module manifest is runtime state and may need to be regenerated after Composer or Git operations.
- Existing scoped values remain in `config_scope_values`; ownership moved to `zoosper/scoped-config` without changing the table contract.

## Verification baseline

- 1,472 Pest tests passed with 8,672 assertions.
- Standard quality gate passed with zero errors and zero warnings.
- Fresh-install smoke, frontend boot, Composer validation, security-advisory checks, and a fresh 34-module manifest passed.

## Known alpha limitations

- Public contracts may continue to evolve during the alpha line.
- Not every Admin-managed capability has full public API parity.
- Form Builder, the full documentation website, and complete third-party extension examples remain future work.
- Deployment automation remains environment-specific.
