# Zoosper documentation

This directory is the canonical source for the future documentation website at `docs.zoosper.com`.

Documentation describes the current product, architecture, developer contracts, operating procedures and roadmap. Completed implementation phases are preserved in Git history and release tags, not as permanent documents.

Temporary planning, audit, migration and phase documentation must be merged into durable documentation or removed before a phase is complete.
