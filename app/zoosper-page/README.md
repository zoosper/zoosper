# Zoosper Page

The Page module owns site-scoped page persistence, Admin CRUD, publication, preview, frontend rendering, Editor.js content integration, SEO metadata and revision snapshots.

Page controllers are thin HTTP adapters. Save, publication, Grid, form, preview and revision behaviour belongs to Page-owned collaborators. Shared presentation contracts are consumed through interfaces.

See the canonical [user guide](../../docs/user-guide.md), [architecture guide](../../docs/architecture.md) and [Admin extension guide](../../docs/admin.md).
